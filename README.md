# 创业资讯收集 · Startup Intel

个人静态资讯台：AI 数字产品 / 独立 Side Project 的素材调研、选题、脚本模板与参考账号库。

## 本地预览

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

静态产物在 `dist/`。已用 `base: './'` + `HashRouter`，方便挂到 GitHub Pages / 任意静态托管。

## 路由

| 路径 | 内容 |
| --- | --- |
| `/` | 总览 |
| `/#/overseas` | 海外调研 |
| `/#/domestic` | 国内资讯 |
| `/#/bilibili` | B站叙事参考 |
| `/#/douyin` | 抖音短视频参考 |
| `/#/tiktok` | TikTok 参考 |
| `/#/tools` | 剪辑工具 |
| `/#/templates` | 制作模板 |
| `/#/keywords` | 关键词库 |
| `/#/titles` | 标题封面 |
| `/#/workflow` | 执行规则与自检 |
| `/#/gamedev` | 游戏开发社区 |
| `/#/partners` | 合作招募渠道 |

## 后续加链接

把新条目加到 `src/data/` 对应文件即可，页面会自动渲染。
